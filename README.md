# Inventario en campo

App para iPhone que acompaña al programa de escritorio «Sistema central de inventarios». Sirve para verificar bienes en las sedes, cambiar su estado o ubicación, tomar fotos y registrar bienes nuevos, incluso sin señal.

Abre la dirección de GitHub Pages en Safari y usa **Compartir → Agregar a pantalla de inicio**.

Este repositorio contiene solo el programa. Los datos del inventario se guardan en el celular y viajan al computador como archivos por OneDrive; nunca se suben aquí.
